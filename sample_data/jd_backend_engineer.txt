Job Title: Backend Software Engineer
Company: CloudTech Solutions
Location: New York, NY (Hybrid)

ABOUT THE ROLE
We are looking for a skilled Backend Software Engineer to join our growing engineering team.
You will design, build, and maintain scalable REST APIs and microservices powering our
cloud-based SaaS platform.

RESPONSIBILITIES
- Design and implement high-performance REST API services using Python (Django/FastAPI)
- Build and manage containerized applications using Docker and Kubernetes
- Write and optimize complex SQL queries for PostgreSQL databases
- Deploy and maintain services on AWS (EC2, S3, RDS, Lambda)
- Collaborate with frontend engineers on API contracts and integration
- Participate in code reviews and maintain high code quality standards
- Implement CI/CD pipelines using GitHub Actions or Jenkins
- Monitor system performance and troubleshoot production incidents

REQUIRED SKILLS AND QUALIFICATIONS
- 1-3 years of experience in backend software development
- Strong proficiency in Python; knowledge of Django or FastAPI preferred
- Experience with RESTful API design and development
- Proficiency in SQL and relational databases (PostgreSQL or MySQL)
- Hands-on experience with Docker and containerization
- Familiarity with AWS cloud services (EC2, S3, Lambda, RDS)
- Solid understanding of Git and version control workflows
- Experience working in Agile/Scrum teams
- Strong problem-solving and communication skills

NICE TO HAVE
- Experience with Kubernetes or container orchestration
- Knowledge of Redis for caching
- Familiarity with microservices architecture
- GraphQL API experience
- CI/CD pipeline experience (Jenkins, GitHub Actions)

WHAT WE OFFER
- Competitive salary and equity package
- Remote-friendly team
- Modern tech stack
- Learning & development budget
